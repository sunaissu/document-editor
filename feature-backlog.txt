document-editor feature backlog
12 October 2026

Scope and status

This is the implementation contract for all 29 candidate features in this package's existing backlog. OPEN and PARTIAL entries are unfinished work. An implementation plan is not evidence that a feature has shipped. Each entry below gives concrete work, dependencies and acceptance checks. No entry is complete merely because an API type, toolbar button or passing smoke test exists.

Current review

Added optional host image uploads with file/paste/drop admission, cancellation, stable insertion anchors and late-result guards. Captions use portable plain paragraphs; richer media editing remains partial.

This pass preserves link destinations with unmatched parentheses, link/image titles and literal image descriptions. Preview search and outline navigation use source offsets, including duplicate formatted headings and CRLF input. Imperative source insertion and mode changes defer during composition. Arbitrary Markdown extension roundtrips remain outside the supported subset.

Suggested implementation order

1. Finish navigation, preservation and media: DOC-01, DOC-02, DOC-04, DOC-22 and DOC-29. Keep DOC-03, DOC-05 and DOC-16 covered by regression tests.
2. Define extensibility and host contracts: DOC-23, DOC-09, DOC-07, DOC-19, DOC-18, DOC-20 and DOC-24.
3. Add richer authoring: DOC-06, DOC-08, DOC-10, DOC-11, DOC-12, DOC-13, DOC-17, DOC-21 and DOC-27.
4. Add conversion and connected content: DOC-14, DOC-15, DOC-25, DOC-26 and DOC-28.

Package boundaries

The calculator owns mathematical evaluation and versioned calculation definitions. The document editor and Noteboard own their editing, rendering, serialization and undo behavior. The host owns storage, authentication, authorization, synchronization providers and permission-aware resolution of linked content. Cross-package dependencies use the existing CAL/DOC/NBD identifiers. Keep host callbacks optional and report async failures without losing local work.

Definition of done

For each feature, complete the public types, working UI or documented engine API, serialization/migration when needed, history/read-only behavior, error states, README example and the acceptance checks below. Add a regression that fails before a bug fix. Test user outcomes rather than mirroring private helpers. Mark IMPLEMENTED only after the relevant checks pass and list any host prerequisite.

Release checks

Run npm test, npm run playground:build and npm pack --dry-run --json. Inspect CJS, ESM, declaration files and every README-linked package file in the tarball. Run the documented browser suites for changed workflows, including keyboard and narrow light/dark layouts. Audit root and playground dependency trees. Record exact commands and results in implementation-review.txt.

For shared-schema changes, back up authoritative state, document migration and rollback, test old-data import, and prevent incompatible clients from reconnecting. Provider authentication, durable persistence and reconnect behavior require a host integration test; in-memory Yjs tests do not certify them.

Feature contracts

DOC-01 Find and replace
Status: IMPLEMENTED
Dependencies: None.
Implementation: Existing literal search, case/word options, source navigation and replace-all confirmation remain. Preview now navigates by source ranges. Add a contextual replacement preview before claiming a full diff preview.
Acceptance: Cover repeated matches, Unicode offsets, zero matches, read-only preview and changes arriving while confirmation is open.

DOC-02 Outline and folding
Status: PARTIAL
Dependencies: None.
Implementation: Use source ranges for headings and add local section-collapse state keyed by stable anchors; expose keyboard folding controls.
Acceptance: Duplicate and formatted headings navigate correctly; folding does not delete text or enter shared undo.

DOC-03 Tables
Status: IMPLEMENTED
Dependencies: None.
Implementation: Existing insertion and contextual row/column/alignment/delete controls are implemented. Maintain limits and one-action undo.
Acceptance: Run table regression tests and browser insertion/undo checks in visual and source modes.

DOC-04 Images
Status: PARTIAL
Dependencies: None.
Implementation: Host upload callback, file/paste/drop admission, pending/failure/cancel states, captured insertion positions, literal alt text and plain-paragraph captions are implemented. Percentage progress, pre-upload preview and dedicated caption editing remain.
Acceptance: Chrome checks cover visual/source anchors, captions, undo, late completion after cancellation, changed document, read-only and unmount. Unit checks reject unsafe destinations and oversized/unsupported files. Test real storage and its authorization in the host.

DOC-05 Slash menu
Status: IMPLEMENTED
Dependencies: None.
Implementation: Existing 31 commands support visual/source input, keyboard selection and composition/code guards. Keep command definitions shared with future palettes.
Acceptance: Run slash unit and browser suites; no activation inside code, composition or read-only views.

DOC-06 Move and duplicate blocks
Status: OPEN
Dependencies: DOC-22.
Implementation: Use parsed source ranges for block commands and drag handles; preserve surrounding syntax and relative selections.
Acceptance: Nested lists, tables and fenced code move as complete blocks; one undo restores the move; keyboard actions match drag behavior.

DOC-07 Comments
Status: OPEN
Dependencies: DOC-09 anchor support.
Implementation: Define host-owned thread records and resilient text anchors, plus create/reply/resolve/reopen callbacks and orphan handling.
Acceptance: Concurrent edits move anchors safely; deleted ranges become orphaned threads; permissions apply to every thread action.

DOC-08 Suggestions
Status: OPEN
Dependencies: DOC-07.
Implementation: Represent suggestions as proposed edits against a base revision with accept/reject actions and conflict detection.
Acceptance: Accept applies only the intended change; reject leaves content untouched; stale proposals cannot overwrite peer edits.

DOC-09 Presence
Status: OPEN
Dependencies: None.
Implementation: Define an optional awareness interface for peer identity, source selection and relative Yjs positions; render visual/source selections without changing content.
Acceptance: Disconnect removes presence; edits rebase anchors; composition, throttling and multiple editor instances are covered.

DOC-10 Math
